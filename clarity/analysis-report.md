## ⚙️ 六、数据质量发现（建议后续优化）

1. **URL.csv 与 Source.csv 内容完全相同**（diff 一致）。根因：`flatten()` 函数**没有使用 `dim` 参数**，URL 与 Source 两个维度输出的是同一份全量数据。本次导出实际只拉取了 URL 维度，Source 维度未生效。
   > ✅ **已修复（PR #20）**：`flatten()` 现按 `dim` 过滤——URL 维度保留 `Url` 非空行，Source 维度保留 `Source` 非空行，URL/Source CSV 已真正差异化（URL=1490 行、Source=171 行）。
2. 首页 `/zh` 有 2 行同 URL 数据（Source 空 13 会话 / Source=www.limingdao.com 3 会话），属于正常的维度拆分，但 CSV 未按 Source 列拆行语义输出，审计时易混淆。
3. `distinctUserCount` 累加口径易误读，建议脚本汇总时标注「按页面行累加、非去重」。
