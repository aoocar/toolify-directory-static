## 一、已落地：IndexNow 主动推送（全自动，2026-08-08）

**IndexNow** 是 Bing / 百度 / Yandex / Seznam 等搜索引擎共同支持的「主动提交」协议。
新站 / 新页面发布后，把 URL 列表 POST 给 IndexNow API，搜索引擎会在**数小时**内抓取，
远快于自然爬行（数天~数周）。这是新站爬坡期「被看见」最有效的低成本自动化手段。

### 实现

| 组件 | 文件 | 说明 |
|---|---|---|
| 密钥文件 | `public/88b9bf2dedaf4503a16cbad4681b06e5.txt` | IndexNow 域名所有权证明（32 位 hex），部署后线上可访问 |
| 推送脚本 | `scripts/indexnow-submit.py` | 从 sitemap 收集 URL → POST 到 `api.indexnow.org`；支持 `--limit` / `--dry-run` |
| 自动触发 | `.cnb.yml` → `main: push` 流水线 | 每次发布新内容后自动推送核心 URL，无需手动 |

### 验证方法

1. `curl -s https://www.limingdao.com/88b9bf2dedaf4503a16cbad4681b06e5.txt` → 返回密钥即证明域名所有权；
2. 在 [Bing Webmaster](https://www.bing.com/webmasters) 或百度资源平台确认 IndexNow 已生效；
3. 用 `scripts/check_ai_visibility.py` 月度复测 CC 覆盖（目标 ≥ 1 批次）。

### 外链质量红线（遵守仓库纪律）

- 不在垃圾站 / 站群 / PBN 发布；
- 不在明显违反平台规则的地方发（会反噬）；
- 回链一律指向 https://www.limingdao.com/ 或核心栏目页（/zh/tools、/zh/guides、/zh/accounts）；
- 不发重复内容，每个平台一条有信息量的介绍即可。
