## 二、Common Crawl（大模型训练语料主源）实测明细

> Common Crawl 是 GPT/Claude/文心/豆包等大模型训练与 AI 搜索引擎抓取的最主要公开语料源之一。**语料里没有你的页面 = AI 大概率不知道你存在。**

### 2.1 各爬取批次覆盖情况

| CC 批次 | 爬取时间 | 首页(200) | 新站 /zh | 新站 /tools | /guides | /accounts | /services | /llms.txt |
|---|---|---|---|---|---|---|---|---|
| CC-MAIN-2026-17 | ~2026-04 | ❌ | 0 | 0 | 0 | 0 | 0 | 0 |
| CC-MAIN-2026-21 | ~2026-05 | ❌ | 0 | 0 | 0 | 0 | 0 | 0 |
| CC-MAIN-2026-25 | 2026-06-11 | ✅ 旧站首页 | 0 | 0 | 0 | 0 | 0 | 0 |
| CC-MAIN-2026-30 | 2026-07-16 | ❌ | 0 | 0 | 0 | 0 | 0 | 0 |

> 说明：`/categories` 前缀在 CC-21/CC-30 有 1–3 条记录，但均为**旧站 `/categories/*` 的 404 快照**（`crawldiagnostics`），不是新站页面，不计入新站覆盖。

### 2.2 详情

- **2026-06-11（CC-25）**：抓到旧站 Hugo 首页（title「Limingdao 黎明岛 - 互联网工具资源知识引擎」），是新站上线前的旧站快照。
- **2026-07-16（CC-30）**：抓到 52 条**旧站 `/bookmarks/*` 与 `/categories/*` 的 404 快照**（`crawldiagnostics` 目录），新站路径 `/zh` `/en` `/tools` `/guides` `/accounts` `/services` `/llms.txt` **全部 0 条**。
- 说明：CC-30 批次爬取时（7 月中旬）新站已在线上（`/zh` 200），但仍未被 CC 抓取到——这符合新域名/新站点在 CC 中的**滞后爬取**特性。

### 2.3 影响

- AI 搜索引擎（Perplexity 等）和中文大模型联网检索时，**无法从 CC 语料获取本站信息**；
- 站点的 GEO 价值（`llms.txt`、结构化数据、FAQ）**尚未被 AI 引擎消费**；
- 需要主动「喂料」加速覆盖（见 §五 行动建议）。

## 五、行动建议（按优先级）

### 🔴 P0：加速 AI 语料覆盖（本月内）
1. **向 Common Crawl 提交站点 URL**（可选）：`https://index.commoncrawl.org/` 的提交入口不公开，但可通过**主动在外部平台发布内容并附带本站链接**间接加速（外链是 CC 发现的第二驱动）。
2. **确保 sitemap 持续可抓**：已在 `robots.txt` 声明；新站 URL 加入 GSC 并「请求编入索引」。
3. **外链建设**：在 AI 工具导航站、技术社区、知乎/掘金等发布黎明岛内容并回链，让 CC/爬虫更快发现新站。

### 🟡 P1：品牌词破「黎明撞名」
1. 内容标题统一带「黎明岛」+ 领域词（如「黎明岛 · AI 工具导航」「黎明岛 · 创作者目录」），强化品牌+业务关联；
2. 持续产出（每周）领域指南，用**长尾词**（`黎明岛 AI 工具`、`黎明岛 创作者导航`）绕开「黎明」主词竞争。

### 🟢 P2：固化复测
- 每月随 GSC 审计一起跑 `scripts/check_ai_visibility.py`，记录 CC 覆盖数、搜索引擎露出变化；
- 目标：**2 个月内 CC 覆盖新站 ≥ 1 个批次**、GSC 从 0 点击 → 有自然点击。
